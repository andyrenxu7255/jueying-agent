## 前端 i18n 机制

### localization.js 结构

```javascript
LOCALE = { lang: 'zh-CN', zh: {...}, en: {...} }

t(key)         // 查当前语言词条，key 不存在时 fallback 到 key 本身
setLang(lang)  // 切换语言，保存到 localStorage('ah_lang')，重新 renderApp+renderView
initLang()     // 从 localStorage 读取并设置初始语言
```

### 语言切换按钮

- 位置：侧边栏 JueYing 标题右侧
- 显示文字：当前为中文时显示 "English"，当前为英文时显示 "中文"
- 点击后立即切换并 re-render 整个界面

### 已翻译的区域

登录页、改密弹窗、初始化向导、侧边导航（21项）、系统指南（架构/能力/故事线标题和概述/快速上手）、仪表盘、Workflow控制台、任务接入、审批台、系统配置、用户管理、组织管理、技能管理、知识导入、知识审核、共享知识库、任务分发、我的任务、审计日志、检索追踪、身份绑定、数据库运维、资源监控、梦境模式（3个标签页全部）

### 未翻译的区域（有意保留中文）

- `renderGuideArch()` 中架构图层的 **节点名称和描述**（保留中文作为架构图标签）
- `renderGuideStories()` 中 **21 条场景故事的正文**（大约 250 行中文正文，保留原文）
- 快速上手表格中的 **步骤描述**

### 调试前端 i18n

1. 打开浏览器 DevTools Console
2. `LOCALE.lang` — 查看当前语言
3. `t('some.key')` — 测试单个翻译
4. `setLang('en')` / `setLang('zh-CN')` — 手动切换
5. `localStorage.getItem('ah_lang')` — 查看持久化语言

## 后端 i18n 机制

### libs/shared/src/i18n.ts

```typescript
t(lang: string, key: string): string              // 纯文本翻译
tf(lang: string, key: string, vars?: {}): string   // 带变量替换 {varName}
```

### gateway-adapter 改造

- 所有用户可见消息（~55 条）使用 t/tf，默认 `lang='zh-CN'`
- LLM system prompt 中英双语，根据 lang 参数选择
- 语言尚未与用户自动关联（用户/profile 中暂无 lang 字段），当前均为 `zh-CN`

### web-portal API 改造

- 所有 `sendJson` 中的 `message` 字段（~18 条）使用 t()
- `CONFIG_SECTIONS` 的 label 字段使用 t()
- `validatePasswordStrength()` 的消息使用 t()
- `checkLoginRateLimit` 和 `recordLoginFailure` 消息使用 tf() 带变量

## 文档双语化

每份文档保持中文原文不变，末尾追加英文翻译：

- 分隔标记：`---` + `## English Version / 英文版`
- 覆盖内容：所有人类可读文本（标题、段落、表格、说明）
- 保留内容：代码示例、URL、文件路径、端口号、API 端点不变

## 已知限制

1. **后端语言检测**：网关和后端暂不支持根据用户/渠道自动检测语言，当前全部默认为 `zh-CN`。未来可在 `normalized` 中增加 `lang` 字段，或从 `user_profile` 读取偏好语言。
2. **CONFIG_SECTIONS meta API**：`/api/admin/config-meta` 返回的 label 在模块加载时静态计算，如果语言切换后重新请求 config-meta，label 会跟随当前请求语言（因为 t() 在模块顶层调用时用 `zh-CN` 做默认值）。如果需要运行时根据 `Accept-Language` header 切换，需要将 CONFIG_SECTIONS 改为函数。
3. **故事线正文**：场景故事线 21 条正文未翻译（约 250 行中文长文），属于产品文档性质，如需可后续追加。
4. **前端架构节点名称**：guide架构图上 6 层的中文标签未翻译，这些是可视化图表标签，需额外考虑布局。
